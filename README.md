# 시그널 (Signal)

커플이 서로의 상태(빨강/노랑/초록)를 간단히 공유하는 앱입니다.

## 개인정보 처리방침 (Privacy Policy)

시그널(이하 '앱')은(는) 「개인정보 보호법」 제30조에 따라 이용자의 개인정보를 보호하고 이와 관련한 고충을 신속하고 원활하게 처리할 수 있도록 하기 위하여 다음과 같이 개인정보 처리방침을 수립·공개합니다.

### 개인정보의 처리 목적

본 앱은 다음의 목적을 위하여 최소한의 정보만을 처리하며, 수집된 정보는 목적 이외의 용도로는 이용되지 않습니다.

- **서비스 제공**: 회원 가입 및 인증, 파트너 연결(페어링), 상태(시그널) 공유 기능 제공
- **알림 발송**: 파트너의 상태 변경 시 실시간 푸시 알림(FCM) 발송

### 처리하는 개인정보 항목

본 앱은 사용자의 민감한 개인정보(이름, 주민등록번호 등)를 직접 수집하지 않습니다. 다만, 서비스 이용 과정에서 서비스 제공 및 알림 발송을 위해 아래와 같은 항목이 수집되거나 권한이 사용될 수 있습니다.

- **수집 항목 (Firebase)**: 휴대폰 번호(로그인 인증), 닉네임, 현재 시그널 색상 및 변경 시각, 이용자가 직접 설정한 색상별 상태 문구, 파트너 연결 정보(페어링 식별자), 푸시 알림 발송을 위한 FCM 토큰
- **자동 수집 항목**: 없음 (광고·분석 SDK를 사용하지 않습니다)
- **선택 권한**: 알림(Notification) — 파트너의 상태 변경을 실시간으로 알리기 위해 사용합니다. 거부하더라도 앱 이용은 가능하며, 실시간 알림 수신만 제한됩니다.

홈 화면 위젯에 표시되는 파트너 상태 정보(닉네임, 색상, 문구)는 기기 내부(로컬 저장소)에만 캐시되며, 외부로 전송되지 않습니다.

### 개인정보의 제3자 제공 및 수집

본 앱은 이용자의 개인정보를 원칙적으로 외부에 제공하지 않습니다. 다만, 안정적인 서비스 제공을 위해 다음과 같은 제3자 서비스를 이용하며, 해당 서비스 제공업체의 인프라 내에 데이터가 보관될 수 있습니다.

**구글 파이어베이스 (Google Firebase)**
- 제공 목적: 회원 인증(Auth), 데이터베이스 저장(Firestore), 푸시 알림 발송(FCM), 서버 로직 실행(Cloud Functions)
- 개인정보 처리방침: https://policies.google.com/privacy

### 개인정보의 파기

이용자가 파트너와의 연결을 해제하는 경우, 앱 내 위젯 캐시 등 기기에 남아있던 파트너 관련 정보는 즉시 삭제됩니다. 계정 자체의 삭제(회원 탈퇴)를 원하시는 경우 아래 문의처로 요청해 주시면, 파이어베이스 서버에 저장된 이용자 데이터를 지체 없이 안전하게 파기합니다. 단, 관계 법령에 따라 보존이 필요한 경우 해당 기간 동안 보관 후 파기합니다.
